RENDER BACKEND — READY TO DEPLOY

Upload this folder to a PRIVATE Git repository, then create a Render Web Service/Blueprint using render.yaml.

Required Render environment variables:
  DB_HOST=<Supabase host>
  DB_PORT=5432
  DB_NAME=postgres
  DB_USER=<Supabase user>
  DB_PASSWORD=<Supabase password>
  DB_SSLMODE=require
  APP_TIMEZONE=America/Chicago

Optional:
  FRONTEND_ORIGIN=https://YOUR-NETLIFY-SITE.netlify.app

Health check after deploy:
  https://YOUR-RENDER-SERVICE.onrender.com/health.php
Expected database status: connected.
